# Taller 1 – BiblioRed 📚

Construimos la base de una red de bibliotecas: socios, libros, ejemplares, préstamos, reservas y multas.

**Orden:** `01_ddl.sql` → `02_dml.sql` → `03_dql.sql` → `04_dql_avanzado.sql` → `05_tcl.sql`.

Los datos son ficticios. Ejecuta cada fase, revisa los resultados y usa el anexo de procedimientos para practicar funciones y consultas adicionales.
