# Taller 2 – FlotaYa 🚗

Construimos la base de una empresa de alquiler de vehículos: clientes, carros, reservas, contratos, inspecciones, daños y pagos.

**Orden:** `01_ddl.sql` → `02_dml.sql` → `03_dql.sql` → `04_dql_avanzado.sql` → `05_tcl.sql`. Los retos están en `06_retos.sql`.

Los datos son ficticios. Prueba cada bloque en MySQL Workbench y verifica especialmente las transacciones y los permisos.
